Каналы
На этом VPS каждый Gateway peer является отдельным management-каналом. Изменения применяются ownership-scoped root transaction с rollback.

Приватный ключ сохраняется в закрытом state только до первого скачивания. После выдачи `.conf` он удаляется с VPS; повторное скачивание невозможно. Такой ключ работает только в режиме ROUTED_HUB и не может использоваться для end-to-end relay.

        

        

      


      

        
End-to-end relay
VPS пересылает только ограниченный UDP-поток к выбранному Gateway. Внутренний wg-admin завершается на Gateway, поэтому его приватного ключа на VPS нет.

Граница доверия
Relay выполняет только bounded UDP DNAT/SNAT к фиксированному порту 51822 выбранного Gateway. VPS не получает внутренний private key, не расшифровывает сессию администратора и не создаёт произвольные firewall-правила.
Сначала создайте внешний ключ администратора в режиме END_TO_END_RELAY, затем настройте соответствующий wg-admin peer на Gateway.

Watchdog VPS Hub
Показывает control-plane и последнюю root-проверку Management Fabric. AmneziaVPN, Docker, UFW и чужие WireGuard-интерфейсы исключены.

        

      


      

        
Журналы VPS Hub
Разделённые эксплуатационные записи Gateway VPN. Команды host из WebUI не запускаются: root-снимок собирается отдельным ограниченным таймером.

Диагностика VPS Hub
Один ограниченный ZIP для разбора неисправностей. Приватные ключи, пароли, токены и содержимое backup в архив не включаются.
